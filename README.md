# 雀乐 for MyGo Music

适用于 [MyGo Music](https://github.com/egoist/mygo-music) 的第三方雀乐插件。插件直接访问雀乐接口，不代理、存储或重新分发音乐内容。

- 插件 ID：`mygo-queyue`
- 当前版本：`0.1.0`
- 运行方式：原生 JavaScript，无第三方依赖、无需构建
- 界面语言：跟随 MyGo Music，支持英文和简体中文

## 安装

1. 下载或克隆本项目，确认目录内包含 `plugin.json` 和 `index.js`。
2. 在 MyGo Music 中打开 **设置 > 插件**。
3. 点击 **+ > 显示插件文件夹**。
4. 将整个 `mygo-queyue` 文件夹复制到该目录，然后在 MyGo Music 中启用“雀乐”。
